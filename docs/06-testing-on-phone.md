# Testing the OpenVault test APK on a phone

**What it is:** a *test build* (0.1.0-test), debug-signed, Android 8.0+ (minSdk 26). Plain Android framework UI
(no Compose/AndroidX). It uses the same JVM core that is covered by 228 automated tests, but **the app layer itself has
never been run on a device or emulator** (none was available when it was built). Expect rough edges.

**Download:** https://github.com/alma92350/EDS-NG/raw/claude/dreamy-gates-pn6dzv/app/dist/openvault-0.1.0-test.apk  (QR code: `docs/apk-qr.png`)

## Install
1. Copy `openvault-0.1.0-test.apk` to the phone, open it, allow "install unknown apps" for your file manager/browser.
2. No permissions are requested (no network, no storage); the app only touches files you pick in the system file picker.

## Test containers (passwords)
| File | Password | Notes |
|---|---|---|
| `test-sha512.hc` | `test` | AES, SHA-512, FAT16: `hello.txt`, `docs/readme.txt`, `data.bin` |
| `test-hidden.hc` | outer `outer`, hidden `inner` | opens a different tree depending on the password |
| `test-exfat.hc` | `test` | exFAT inside the container (read-only) |

Generated by `tools/make_fixtures.py` (our own implementation of the format), **not** by desktop VeraCrypt. A real
desktop-VeraCrypt container (AES + SHA-512/SHA-256/BLAKE2s, FAT or exFAT, no cascades/Argon2) is the best real test.

## Things worth checking
* Add container -> unlock (read-only first), browse, open a text file and an image, Lock from the menu.
* Wrong password gives the single generic message. "Try all hash algorithms" is only needed for Whirlpool/Streebog.
* Unlock time on your phone (SHA-512 desktop JVM: 0.6 s; phone will be several times slower).
* Uncheck read-only, import a file, export a file, rename/delete; then open the container on a desktop with VeraCrypt.
* Hidden volume: unlock `test-hidden.hc` with each password; with write access, tick "Protect hidden volume".
* Screen off or inactivity (default 5 min) locks the vault; recents preview is blank (FLAG_SECURE).

## Known limits of this build
* No system file-picker provider (DocumentsProvider): other apps cannot open files inside the vault yet; use Export.
* No foreground service/notification; if Android kills the process the vault is simply locked.
* Folder import, search, thumbnails, zoom, settings screen beyond auto-lock are not implemented.
* Keep backups of any real container; prefer read-only.

## Rebuild
```bash
sudo apt-get install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23 maven
tools/build_apk.sh          # -> app/dist/openvault-0.1.0-test.apk (debug key: app/debug.keystore, password openvault-debug, public)
```
